# 광영고 이수 과목 검증기

나이스 교과학습발달상황 엑셀(.xlsx)을 올리면 학점 배당표 기준으로 학생별 이수 학점·과목을 점검하는 웹 페이지입니다.

- **성적 파일로 일괄 검사**: 여러 반 파일을 한꺼번에 올려 학점 미충족·과목 확인 필요 학생을 찾고, 공동교육과정·온라인학교로 인한 시수 차이를 따로 보여 줍니다.
- **전입생 검증**: 같은 학년과 과목 구성이 유독 다른 학생을 찾아 빠진 과목과 대체 후보를 보여 줍니다.
- **학생 1명 직접 체크**: 과목을 체크해 한 학생의 이수 현황을 확인합니다.
- **학점 배당표**: 입학년도별 배당표 엑셀을 올려 적용합니다. (2025·2026학년도 입학 배당표 내장)
- 결과는 엑셀, HTML·PDF 보고서로 저장할 수 있습니다.

올린 파일은 브라우저 안에서만 읽고 어디에도 전송하지 않습니다.
