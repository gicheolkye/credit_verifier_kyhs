검사 방법

  1. 파일 위쪽의 'O학년 O반'과 출력일로 입학년도를 정해 해당 배당표를 적용해요. (2026학년도 기준 1학년 → 2026 입학, 2학년 → 2025 입학) 배당표는 '학점 배당표' 탭에서 올리거나 바꿀 수 있어요.
  2. 검사 범위는 1학년은 1학년 1·2학기, 2학년은 1학년 1학기부터 2학년 1학기까지예요. 단, 파일에 아직 성적이 없는 학기는 빼고 검사해요.
  3. 일반 교과, 체육·예술/과학탐구실험, 교양 세 구역을 모두 읽어 학교지정 과목, 음악·미술 같은 교차 이수 과목, 학년선택 택4·택1, 국·수·영 15학점 상한을 확인해요.
  4. 학점으로 판정해요. 학생마다 검사 범위 안에서 이수한 학점(성적 파일의 학점 합, 미이수 처리 과목 제외)을 같은 학년 다른 학생들이 가장 많이 이수한 학점과 비교해, 적으면 학점 미충족이에요. 학점은 채웠지만 배당표 과목이 빠져 있으면 과목 확인 필요로 따로 보여 줘요.
  5. 같은 반 80% 이상이 똑같이 빠진 과목은 성적 미입력이나 반별 편성 차이일 수 있어 따로 모아 보여 줘요.

올린 파일

기준 학점 같은 학년 학생들이 가장 많이 이수한 학점(최빈값)보다 적으면 미충족

시수 차이 원인 기준 학점과 다른 학생 중 공동교육과정·온라인학교 과목 때문인 경우를 따로 모았어요

반 전체 공통으로 빠진 과목 성적 미입력이거나 반별 편성 차이일 수 있어요

    성적 파일을 먼저 올려 주세요

    전입생 검증은 '성적 파일로 일괄 검사' 탭에 올린 파일로 같은 학년 학생들과 비교해요.

    이렇게 찾아요

    • 비고 '전입학'이 붙은 과목이 있으면 전입생으로 확정해요.
    • 비고가 없어도, 같은 학년에서 3% 미만만 들은 과목(공동교육과정·온라인학교·타기관 과목은 제외)이 있거나 같은 과목인데 학점이 다른 과목이 2개 이상이면 전입 추정으로 봐요.
    • 빠진 배당표 과목마다 같은 교과(군)에서 들은 배당표 외 과목을 대체 후보로 짝지어, 학점까지 채워지는지 봐요. 대체 인정 여부는 학교가 판단해 주세요.
